The code in this repository is MIT-licensed (see `LICENSE`). Copy it, change it,
ship it, sell it. The MIT license covers the code and nothing else.

It does not cover the name **Bitflash**, the ticker **BTF** as the name of this
network's coin, the Bitflash logo, the domain **bitflash.network** and its
subdomains, or the Bitflash accounts on Discord, Nostr and elsewhere. Those
identify this project and this network, and they are not licensed to anyone.

What that means in practice:

- **A fork needs its own name.** Software derived from this code that is not
  released by this project may not be called Bitflash, may not use the logo, and
  may not present itself as Bitflash, an official Bitflash client, or "Bitflash
  Core". Say it is a fork of Bitflash if you like; do not say it is Bitflash.
- **A separate network needs its own name and ticker.** A chain with a
  different genesis block, different network parameters or different consensus
  rules is a different coin. It may not be called Bitflash or trade as BTF.
- **Only signed releases are Bitflash.** A build is a Bitflash release only if
  its `SHA256SUMS` is signed by the project's release key,
  `910A 2B4C CA87 9E81 FB4B 2AEA 1D4A 53D3 B78A A4B8`. Anything else, whatever
  it is called, is somebody else's build.
- **The pool and seed names are not yours either.** Do not present a node,
  pool, explorer or website as "bitflash.network" or as operated by this
  project when it is not.

Reasonable, truthful references are fine and need no permission: "built on
Bitflash", "compatible with the Bitflash network", "a fork of Bitflash", a
library that talks to a Bitflash node, a listing on an exchange, an article.

Repositories, packages or sites that use the name or the marks in a way this
document does not allow will be reported to the hosting platform for trademark
misuse.

not already grant. It states what the license never covered.
